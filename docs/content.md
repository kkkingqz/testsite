# Тестові тексти KTAWF

У сайт інтегровані всі 40 пунктів з **`docs/content-source.csv`** (UTF-8, BOM, роздільник `;`). Це дані, надані для демонстраційного наповнення, **не перевірені як реальні факти**. Включно з адресою, телефонним номером, email, заявами про сертифікацію, операційні можливості та міжнародні стандарти — обов'язково перевірте перед публікацією.

## Де редагувати

- Основні блоки, заголовки, галерея, контакти — `public/index.html`.
- SEO-тексти, атрибути `alt` фотографій та `og:image:alt` — у `<head>` і `<img>` файла `public/index.html`.
- Підписи мобільного меню — `public/assets/js/site.js`.
- Текстове слово KTAWF у демонстраційному SVG — `public/assets/images/logo.svg`.
- Сторінки `public/privacy.html` і `public/404.html` перекладено українською.

Сайт залишається чистим статичним HTML/CSS/JS, без розбору CSV в браузері: CSV — **джерело тестових текстів для подальшого редагування**, а не динамічний API або CMS. Зміни в CSV самі не змінюють опубліковану HTML-сторінку.

## Що ще демонстраційне

- Cal.com не підключено; ілюстрація календаря не створює реальні бронювання.
- Зображення `hero-art.webp`, `gallery-*.webp`, `og-image.jpg` і favicon залишаються демонстраційними; їх треба замінити на графіку компанії. OG-файл ще може містити старий бренд Forma до заміни.
- Назва й напис у SVG-логотипі оновлені на KTAWF, проте це **не затверджений фірмовий знак**.
- Для `og:image` треба налаштувати справжній HTTPS-домен замість `example.com`.
- Політика конфіденційності — **не готовий юридичний документ**.
- Текст в описі брифінгу вказує тривалість 45 хвилин, але це не налаштування Cal.com; тривалість та умови доступності знадобиться задати окремо на етапі 3.

## Перевірка

```sh
python3 tests/smoke.py
```

Після зміни вмісту перегляньте сайт на ширинах від 320 px до 1440 px; великі заголовки та довгі переваги адаптовані для переносу рядків.
